# Лабораторная работа №3

Анализ и моделирование данных предметной области

**Цель работы:**
Изучить принципы анализа предметной области и моделирования данных, научиться выделять основные объекты информационной системы, их атрибуты и связи.

**Предметная область:**
Кинотеатр (вариант 7)

**Краткое описание:**
В ходе работы описаны пользователи и процессы кинотеатра и выделены восемь объектов данных: фильм, зал, место, сеанс, клиент, бронирование, билет и оплата. Для объектов определены атрибуты и типы данных, выполнена классификация данных, установлены связи 1:1, 1:N и M:N. По результатам анализа построена концептуальная модель данных (ER-диаграмма) и оценено качество исходных данных.

Полный отчёт: [report/analysis.md](report/analysis.md)
