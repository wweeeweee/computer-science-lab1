# Лабораторная работа №5

## Сравнительный анализ архитектуры цифровых систем

**Вариант:** 7.

**Цель:** сравнить цифровые продукты разных классов, выделить их компоненты и объяснить связь архитектуры с функциями и требованиями к качеству.

**Продукты:** Сервисный портал работника РЖД (корпоративный портал предприятия), Figma Design (SaaS), Яндекс Маркет (маркетплейс).

Изучены открытые описания продуктов, технические публикации и документация API. Для каждой системы приведены функции, сценарий, пять групп компонентов и логическая схема. Сопоставлены масштабируемость, отказоустойчивость и сопровождение; разобраны компромиссы. Подтверждённые сведения отделены от учебных предположений.

Полный отчёт: [report/analysis.md](report/analysis.md).

Три редактируемые схемы Mermaid встроены в отчёт; отдельные исходники находятся в [diagrams](diagrams/). PNG не требуется условиями работы.
